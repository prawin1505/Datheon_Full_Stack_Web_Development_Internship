# 🚀 Datheon – Full Stack Web Development Internship

## 📌 Project Overview

This repository contains three web development projects completed as part of my **Full Stack Web Development Internship at Datheon**.

These projects helped me gain practical experience in frontend development, JavaScript programming, API integration, DOM manipulation, and browser-based data storage.

## 📂 Projects Included

### 1. 💻 Personal Developer Portfolio

A modern, responsive personal portfolio website designed to showcase my technical skills, projects, resume, and contact information.

**Features:**
- Responsive mobile-first design.
- Dark and Light theme toggle.
- Smooth scrolling navigation.
- Interactive hamburger menu.
- Featured projects section.
- Project details popup/modal.
- Resume and contact links.

**Technologies:** HTML5, CSS3, JavaScript (ES6+).

---

### 2. ✅ Task Manager Application

A productivity application that helps users organize and manage their daily tasks efficiently.

**Features:**
- Create, Read, Update, and Delete (CRUD) tasks.
- Categorize tasks into Work, Personal, and Study.
- Set due dates for tasks.
- Mark tasks as completed.
- Filter tasks by All, Active, and Completed status.
- Store tasks using Browser LocalStorage.
- Data remains available after page refresh.

**Technologies:** HTML5, CSS3, JavaScript (ES6+), LocalStorage.

---

### 4. 🛒 E-Commerce Web Application

A modern e-commerce storefront that displays products using the FakeStoreAPI and provides an interactive shopping experience.

**Features:**
- Fetch products from FakeStoreAPI.
- Display product images, prices, ratings, and badges.
- Filter products by category.
- Search products.
- Add and remove products from the shopping cart.
- Increase and decrease product quantities.
- Calculate subtotal, tax, and shipping charges.
- Persistent shopping cart.
- Simulated checkout with order confirmation.

**Technologies:** HTML5, CSS3, JavaScript (ES6+), FakeStoreAPI, LocalStorage.

## ⚙️ How to Run the Projects

1. Clone this repository:

```bash
git clone https://https://github.com/prawin1505/Datheon_Full_Stack_Web_Development_Internship.git
```

2. Open the repository folder in Visual Studio Code.

3. Open the required project folder.

4. Run `index.html` using the Live Server extension or open it directly in your browser.

5. For the E-Commerce project, ensure you have an active internet connection to fetch products from FakeStoreAPI.
